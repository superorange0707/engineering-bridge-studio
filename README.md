# Engineering Bridge Studio marketplace

Ready-to-run Codex plugin for macOS, version 2.0.0-beta.2.

```sh
codex plugin marketplace add superorange0707/engineering-bridge-studio --ref marketplace
codex plugin add engineering-bridge@engineering-bridge-studio
```

Open the plugin in a new Codex task and choose **Open Engineering Bridge Studio**. Follow Studio's project and ChatGPT setup.
